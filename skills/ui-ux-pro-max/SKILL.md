# UI/UX 设计智能助手

## 功能说明

全面的 UI/UX 设计指南，为 Web 和移动端应用提供设计决策支持。包含风格选择、配色方案、字体搭配、交互规范、无障碍检查等完整知识体系。

## 使用场景

- 设计新页面（Landing Page、Dashboard、SaaS、移动端）
- 创建或重构 UI 组件（按钮、弹窗、表单、表格、图表）
- 选择配色方案、字体系统、间距标准
- 审查 UI 代码的用户体验和无障碍性
- 提升界面的专业感和可用性

## 工作流程

### 规则优先级（1→10 依次处理）

| 优先级 | 类别 | 关键检查项 |
|--------|------|-----------|
| 1 | 无障碍 | 对比度 4.5:1、Alt 文本、键盘导航、Aria 标签 |
| 2 | 触摸交互 | 最小 44×44px、8px+ 间距、加载反馈 |
| 3 | 性能 | WebP/AVIF、懒加载、CLS < 0.1 |
| 4 | 风格选择 | 匹配产品类型、一致性、SVG 图标 |
| 5 | 布局响应式 | 移动优先、viewport meta、无水平滚动 |
| 6 | 字体配色 | 基准 16px、行高 1.5、语义化色彩 Token |
| 7 | 动画 | 150-300ms、transform/opacity、有意义 |
| 8 | 表单反馈 | 可见标签、字段旁错误提示、渐进式展示 |
| 9 | 导航 | 可预测的返回、底部导航 ≤5 项 |
| 10 | 图表数据 | 图例、Tooltip、不仅靠颜色传达信息 |

### 设计风格库

支持 50+ 种风格，常用的包括：
- **Glassmorphism** — 毛玻璃效果，适合现代 SaaS
- **Minimalism** — 极简，适合工具类产品
- **Brutalism** — 粗野主义，适合创意/艺术类
- **Neumorphism** — 新拟物，适合控制面板
- **Bento Grid** — 便当盒布局，适合作品集/Dashboard
- **Dark Mode** — 暗色模式，适合开发工具/专业软件

### 核心 UX 准则（精选）

**无障碍（最高优先级）：**
- 文字对比度最低 4.5:1（大文字 3:1）
- 交互元素必须有可见焦点环（2-4px）
- 图标按钮必须有 aria-label
- 不单独依赖颜色传达信息

**触摸与交互：**
- 点击区域最小 44×44pt
- 触摸目标间距最小 8px
- 不依赖 hover 作为唯一交互方式
- 异步操作时禁用按钮并显示加载状态

**动画：**
- 微交互 150-300ms，复杂过渡 ≤400ms
- 只用 transform/opacity，避免动画 width/height
- 尊重 prefers-reduced-motion 设置
- 动画必须表达因果关系，不做纯装饰

**布局：**
- 移动优先设计，向上扩展
- 正文最小 16px（避免 iOS 自动缩放）
- 每行 60-75 字符（移动端 35-60）
- 使用 4pt/8dp 递增间距系统

## 输出规范

根据用户需求输出：
- 风格推荐 + 配色方案 + 字体搭配
- 组件代码（支持 React/Vue/Tailwind/Flutter 等）
- UI 审查报告（按优先级逐条检查）
- 设计系统建议（Token、组件规范）
